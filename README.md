# 11+ Vocabulary & Jumbled-Word Course

Live site: **https://rajesh-nair.github.io/MADHAV11PLUS/**

A personal `/teach` workspace helping Madhav (Year 6, 11+ exam prep) learn
vocabulary and a repeatable strategy for decoding jumbled-word questions,
built from the word list in `indata/vocab_01.md`.

- [`index.html`](index.html) — course home, links to everything below
- [`lessons/`](lessons/) — the C.L.U.E. strategy lesson, plus one growing
  jumbled-word practice page fed by `assets/jumble-data.js`
- [`reference/`](reference/) — printable C.L.U.E. cheat sheet and a running
  vocabulary glossary
- [`MISSION.md`](MISSION.md) / [`RESOURCES.md`](RESOURCES.md) / [`NOTES.md`](NOTES.md) —
  working notes for how this workspace is maintained

See `outdata/` for printable vocabulary tests generated by a separate skill —
that's the testing side of this project; the lessons above are the learning
side.
